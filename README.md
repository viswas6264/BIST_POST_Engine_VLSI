# BIST_POST_Engine_VLSI
Designed an on-chip Built-In Self-Test (BIST) engine in Verilog for a 4-bit adder. Integrated a 4-bit LFSR and an 8-bit signature analyzer to compress test responses into a golden syndrome (0x46). Validated fault observability by injecting a Stuck-At-0 defect on net c2, confirmed via signature mismatch.
